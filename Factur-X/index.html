Portée technique. Le XML généré suit la structure CII (Cross Industry Invoice) du profil Factur-X BASIC — en-tête, parties, lignes, ventilation de TVA, totaux. Le PDF produit est un PDF standard dans lequel ce XML est joint en pièce attachée, conformément au principe Factur-X. La conformité stricte PDF/A-3 (profil colorimétrique ICC, métadonnées XMP complètes) n'est pas garantie côté navigateur : avant tout envoi via une plateforme (Chorus Pro, PDP…), valide le fichier avec un outil officiel (ex. Mustang Project, FNFE-MPE).
